# Voice-Powered-Website
👋 Introduction

Welcome to the Voice-Powered Website, an accessibility-driven project designed to enhance the digital experience for visually impaired users. Our platform enables users to navigate and interact with the website using voice commands—making online browsing easier, faster, and more inclusive.

🎯 Objective

The primary objective of this project is to provide an accessible web experience for blind individuals by integrating voice recognition technology. Users can perform actions like browsing products, adding items to the cart, and navigating different sections of the website—all through their voice.

🧩 Modules

Home Page

Select Mode and Speed (for voice control interaction)

Product Listings

Add to Cart Functionality

🛠️ Tech Stack

Frontend: HTML, CSS, JavaScript

Backend: PHP

Database: MySQL

Development Environment: Visual Studio Code

💻 System Requirements

OS: Windows 11

Processor: Intel i3

RAM: 4 GB

Storage: 256 GB SSD

✅ Conclusion

Creating a voice-based website for blind individuals is not just a technical challenge—it's a step toward digital equity. Our project contributes to making the web more inclusive, enabling visually impaired users to access information and services more independently.
